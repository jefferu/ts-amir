# Tennisschule Amir

Offizielle Webseite & Demo für die Tennisschule Amir Reza (Weiterstadt).

## Übersicht
- Cheftrainer: Amir Reza (ATP A-Level Coach & ehem. Davis Cup Spieler)
- Standort: SG Weiterstadt Tennis
- Partner: Yonex Tennis & Rafa Nadal Academy Talent Scouting

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
